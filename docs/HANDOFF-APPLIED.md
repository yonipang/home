# 인계 자료 반영 · 2026-10-16

## 작업 승인과 범위

사용자는 화면 품질과 앞으로의 제작·확장 환경 개선을 모두 원하며, 코어키퍼 같은 2.5D 시제품 제작을 `yonipang/home`에서 진행하도록 승인했습니다. Godot 시제품 검증 승인이지 본편 전체 이전 결정이 아닙니다.

## 확인한 자료

- GitHub `yonipang/lantern-tree` main의 최신 현황(v72), 기획 결정사항, 개발 계획.
- 첨부 `lantern-handoff (2).zip`의 `HANDOFF.md` 전체와 데모 자산.
- 첨부 상세 게임 기획 가이드.

인계 문서는 본편 순서를 v73 그림 → v74 빛 → 멀티로 기록하지만, 뒤쪽에 순서 미정이라는 과거 문구도 남아 있습니다. 이 시제품에서는 본편 개발 순서의 판단이나 변경을 하지 않습니다.

## 적용

- `a_grass`, `a_water`, `a_cliff`: 사용자 텍스처 기반 이끼·물·물가 앞면.
- `a_wtop_2_0`, `a_wfront_2`: 돌벽의 윗면과 앞면. 연결된 벽 사이에는 앞면을 숨깁니다.
- `pl_down/up/side_0/1`: 기존 데모의 플레이어 그림.
- 흙길을 임의로 추가하지 않습니다.
- 조명 비교 버튼, 한국어 UI, 실기기 미검증 표시.
- 원본 HTML 데모는 게시하지 않습니다. 이번 저장소에는 승인된 Godot 시제품에 필요한 개별 자산만 넣습니다.
- 원본 JPG 시트는 배포하지 않습니다. 구매 에셋으로 잘못 표기하지 않습니다.

## 이번 단계에 포함하지 않은 것

- 자연 바닥의 픽셀 단위 경계·노이즈·부분 갱신 알고리즘. 현재 물가는 격자 기반입니다.
- 화강암 A13·현무암 A17·최종 얼음 타일은 선택 기록만 참고했으며, 해당 지역은 아직 없습니다.
- 광맥·바위 12조합과 광맥 덩어리 밀도. `settleOres()`로 광석 종류를 바꾸는 규칙은 가져오지 않았습니다.
- 데모의 WebGL 후처리·발광·블룸·16광선 그림자 알고리즘은 이식하지 않았습니다. Godot PointLight2D와 LightOccluder2D를 사용합니다.
- 원본 데모의 성능 수치를 이 시제품의 성능으로 인용하지 않습니다.
