## 핵심 규칙 (원작에서 그대로)
- **아주 좋은 날의 다음 날, 동굴에서 있었던 일을 잊는다.** 공책과 손에 익은 것만 남는다.
- 털뭉치는 잊지 않는다. 밤마다 자기 빛을 나무에 주며 작아진다.
- 빛의 원은 날마다 조금씩 줄어든다.

## 단계 1 프로토타입에서 구현한 것
| 기획 | 구현 |
|---|---|
| 행복 게이지 (숨김) | `Happiness` — 같은 행동 반복 시 절반씩 감소. 나무 꼭대기 열매 3개로만 표시 |
| 관계 (부르는 말) | `Relationships` — 교류 2번에 한 단계, 망각 시 초기화 |
| 공책 | `Notebook` — 자동 기록, 오늘의 한 줄, 사람들, 알아낸 것, 뿌리의 금 |
| 공책 읽고 인사하기 | `GameState.greet_from_notebook` — 기록된 단계로 관계 복구 |
| 하루 3구간 · 10분 | `DayClock` — 아침·낮·저녁 각 200초 |
| 1막 강제 망각 | 규칙을 알기 전에는 밤 선택지 없이 잠듦. 첫 망각 후 규칙이 공책에 확정 |
| 밤 선택지 | 그대로 잠들기 / 밤 산책(행복 -30, 털뭉치 빛 -3) / 내일의 나에게 쪽지 |
| 저장 | 잠들 때 저장 + 백그라운드 이어 하기 저장(불러오면 삭제) |
| 조작 | 플로팅 조이스틱 + 탭해서 다가가 말 걸기 |
| 하루에 할 일 (단계 1.5) | `WorldState` — 경계 등불(꺼진 만큼 밤에 원이 줄어듦), 나무 조각·빛버섯 줍기 |
| 이웃의 부탁 | 모루 이층집(나무 조각 9), 할머니 호박(물 4일, 거르면 시듦), 아저씨 낚싯대(관계 2단계) |
| 큰일 = 아주 좋은 날 | 잔치·호박 따기·회차 첫 물고기 각 +60. 평범한 날을 꽉 채워도 100에 닿지 않음 |
| 망각해도 남는 것 | 지은 집, 호박 진행, 주머니. 사라지는 것: 관계, 부탁받은 사실, 빌린 낚싯대 |
| 망각 인지 | 이름표 '?', 처음 만난 대사, 망각 아침 공책 자동 펼침 + 이전의 나의 마지막 줄 |
| 낚시 | 찌가 가라앉는 0.75초 안에 낚아채기, 하루 3번. 일찍 누르면 실패 |
| 빈집 탐사 (단계 2, 원작 2장) | 손등불(빛 방울 1개 = 원 밖 30초, 다 타면 자동 교체). 경계 등불과 빛 방울을 나눠 써서 '오늘은 지킬까, 나갈까'를 고르게 함 |
| 말랑이 | 약한 등불에 끌리고 강한 등불에 물러남. 닿으면 등불이 빨리 닳음. 원 안으로는 못 들어옴 |
| 쓰러짐 | 어둠에서 등불이 꺼지면 나무 아래로 돌아옴. 털뭉치 빛이 줄고(-12), 한 구간 흐름 (원작: 털뭉치가 대신 닳는다) |
| 빈집과 단서 | 빈집 세 채, 단서 10개. 단서는 공책에 남고 망각해도 사라지지 않음. 행복은 오르지 않음(망각을 앞당기지 않게) |
| 단서 잇기 | 공책 '알아낸 것'에서 단서를 골라 이어 보기 → 규칙 4개 확정 (이전의 나들 / 두 번째 나 / 첫 번째 나 / 금의 뜻) |
| 낮 채우기 | 내 집 '잠깐 쉬기'(다음 구간으로), 이층집 완성 후 모루에게 '저녁까지 기다리기' |

## 테스트로 확인한 흐름
매일 성실하게 일하면 첫 망각은 3일째(이층집 완성 → 잔치)에 온다 (`--smoke`가 검사).
