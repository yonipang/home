# 등불나무

행복할수록 잊어버리는 동굴에서, 기록만으로 다음 날을 이어 가는 코지 생활 + 탐사 게임.
웹소설 『등불나무』(50화) 원작. Godot 4.4 · 모바일 세로 우선.

**지금 단계: 단계 1 프로토타입** — 마을 하나, 이웃 셋과 그들의 부탁, 경계 등불, 낚시, 행복 게이지, 망각.
검증하려는 질문은 하나입니다: **"망각한 뒤에도 다시 하고 싶은가?"**

## 해 볼 것

하루는 아침·낮·저녁 10분입니다. 아침마다 털뭉치가 오늘 할 일을 한마디 해 주고, **공책 '오늘' 맨 위**에 할 일이 적혀 있습니다.

**매일 하는 일**
- **경계 등불 켜기:** 나무 뿌리를 탭해 빛 방울을 받고(하루 4개), 원 가장자리의 등불 기둥 6개에 켭니다. 꺼진 등불이 많을수록 밤사이 빛의 원이 줄어들고, 어둠에 먹힌 곳(집·밭·연못)에는 갈 수 없게 됩니다.
- **줍기:** 경계 근처의 나무 조각, 서남쪽 버섯숲의 빛버섯.

**이웃의 부탁 (며칠짜리)**
- **모루의 이층집:** 나무 조각 9개를 건네면 완성됩니다. 완성된 뒤 저녁에 잔치를 열 수 있습니다.
- **할머니의 큰 호박:** 나흘 동안 물을 주면 다 큽니다. 하루라도 거르면 시들어 한 칸 줄어듭니다.
- **구 씨 아저씨의 낚시:** 아저씨가 나를 '자네'라고 부를 만큼 친해지면 낚싯대를 빌려줍니다. 찌가 쑥 가라앉는 순간 낚아채세요. 너무 일찍 누르면 달아납니다.

**잔치·호박 따기·첫 물고기**는 '아주 좋은 날'이 됩니다. 나무 꼭대기 열매 세 개가 모두 밝아지면, 그날 밤 잠든 다음 날…
- 이웃들이 나를 처음 보는 사람으로 대합니다(이름표도 '?'로 돌아갑니다).
- 부탁했던 것도 잊습니다. 하지만 **지은 집, 키운 호박, 주머니의 물건은 그대로**입니다.
- 공책이 저절로 펼쳐지고, 이전의 내가 마지막으로 쓴 줄이 보입니다.
- 두 번째부터는 아주 좋은 날 밤에 선택지(그대로 잠들기 / 밤 산책 / 쪽지)가 나옵니다.
- 이웃에게 다시 말을 걸면 **공책에 적힌 대로 인사하기**로 관계를 되살릴 수 있습니다.

빨리 확인하려면 **공책 → 맨 아래 "테스트용: 시간 10배"** 를 켜세요 (PC에서는 `F`).

## 조작

| 동작 | 휴대폰 | PC | 패드 |
|---|---|---|---|
| 이동 | 화면 아래쪽을 누르고 끌기 (플로팅 조이스틱) | WASD / 방향키 | 왼쪽 스틱 |
| 말 걸기·사용 | 대상을 탭 | 가까이 가서 E / Space, 또는 클릭 | A |
| 공책 | 오른쪽 위 "공책" | Tab | Y |

## 구조

```
scripts/core/     규칙 (행복 게이지, 관계, 공책, 하루 시계, 마을 상태·부탁, 망각, 저장) — 화면과 무관, 테스트 대상
scripts/village/  마을 그리기와 이동
scripts/ui/       조이스틱, 대화창, 공책, 낚시, 하루 마감, 아침 화면
scripts/main.gd   전체 연결
tests/            헤드리스 테스트
docs/             설계 요약과 스크린샷
```

대사를 고치려면 `scripts/core/content.gd`만 수정하면 됩니다.

## 개발

```
godot --headless --import
godot --headless --script res://tests/run_tests.gd   # 단위 테스트
godot --headless -- --smoke                          # 하루를 자동으로 돌려 보기
```
