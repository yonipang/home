# 등불나무

행복할수록 잊어버리는 동굴에서, 기록만으로 다음 날을 이어 가는 코지 생활 + 탐사 게임.
웹소설 『등불나무』(50화) 원작. Godot 4.4 · 모바일 세로 우선.

**지금 단계: 단계 1 프로토타입** — 마을 하나, 이웃 셋, 행복 게이지, 망각.
검증하려는 질문은 하나입니다: **"망각한 뒤에도 다시 하고 싶은가?"**

## 바로 해 보기

휴대폰 브라우저에서 열기: **https://yonipang.github.io/home/**
(`main`에 푸시될 때마다 테스트를 통과하면 자동으로 다시 배포됩니다.)

> 처음 한 번은 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 설정해야 배포됩니다.

## 해 볼 것

1. 커다란 나무 아래에서 깨어납니다. 털뭉치가 따라다닙니다.
2. 이웃을 **탭**하면 걸어가서 말을 겁니다. 이야기할수록 나를 부르는 말이 바뀝니다.
   - 달래 할머니: 새로 온 분 → 호박 좋아하는 분 → 아가
   - 모루: 새로 오신 분 → 이웃님 → 친구
   - 구 씨 아저씨: … → 젊은이 → 자네
3. 화덕에서 빛버섯 수프를 끓이면 털뭉치의 빛이 조금 돌아옵니다.
4. **저녁**에 모루를 찾아가면 잔치를 할 수 있습니다. 나무 꼭대기 열매 세 개가 모두 밝아지면 '아주 좋은 날'입니다.
5. 잠들면… 다음 날 아침을 확인해 보세요. 공책은 남아 있습니다.
6. 두 번째부터는 아주 좋은 날 밤에 **선택지**가 나옵니다 (그대로 잠들기 / 밤 산책 / 내일의 나에게 쪽지).
7. 망각한 뒤 이웃에게 말을 걸면 **공책에 적힌 대로 인사하기**로 관계를 되살릴 수 있습니다.

하루는 10분입니다. 빨리 확인하려면 **공책 → 맨 아래 "테스트용: 시간 10배"** 를 켜세요 (PC에서는 `F`).

## 조작

| 동작 | 휴대폰 | PC | 패드 |
|---|---|---|---|
| 이동 | 화면 아래쪽을 누르고 끌기 (플로팅 조이스틱) | WASD / 방향키 | 왼쪽 스틱 |
| 말 걸기·사용 | 대상을 탭 | 가까이 가서 E / Space, 또는 클릭 | A |
| 공책 | 오른쪽 위 "공책" | Tab | Y |

## 구조

```
scripts/core/     규칙 (행복 게이지, 관계, 공책, 하루 시계, 망각, 저장) — 화면과 무관, 테스트 대상
scripts/village/  마을 그리기와 이동
scripts/ui/       조이스틱, 대화창, 공책, 하루 마감, 아침 화면
scripts/main.gd   전체 연결
tests/            헤드리스 테스트
docs/             설계 요약과 스크린샷
```

대사를 고치려면 `scripts/core/content.gd`만 수정하면 됩니다.

## 개발

```
godot --headless --import
godot --headless --script res://tests/run_tests.gd   # 단위 테스트
godot --headless -- --smoke                          # 하루를 자동으로 돌려 보기
```

Claude와 작업하는 규칙은 [`CLAUDE.md`](CLAUDE.md), 설계 요약은 [`docs/DESIGN.md`](docs/DESIGN.md)에 있습니다.
