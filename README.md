# 등불나무 · 이끼빛 쉼터

Godot에서 **코어키퍼처럼 고정 시점의 픽셀 2.5D 표현과 콘텐츠 제작 흐름**을 시험하는 독립 시제품입니다. 기존 `yonipang/lantern-tree`를 이전하거나 변경한 버전이 아닙니다.

## 실행

1. **Godot 4.4.1 Standard** 또는 호환되는 Godot 4.x Standard를 설치합니다. .NET 버전은 필요 없습니다.
2. 이 저장소의 **Code → Download ZIP**을 누르고 압축을 풉니다.
3. Godot 프로젝트 관리자에서 **Import → project.godot → Import & Edit**를 선택합니다.
4. 최초 이미지·폰트 가져오기가 끝나면 **F6 또는 F5**로 실행합니다. F5가 전체 프로젝트 실행입니다.

검증 엔진은 4.4.1입니다. 새 버전에서는 별도 확인이 필요합니다.

## 웹 배포

GitHub Actions가 `main` 변경 시 테스트 후 Web 빌드를 GitHub Pages에 배포합니다.
최초 한 번 저장소 Settings → Pages → Source를 **GitHub Actions**로 설정해야 합니다.
배포 성공 후 주소: https://yonipang.github.io/home/

단일 스레드 WebGL 2 빌드로 추가 서버 헤더 없이 실행합니다. 브라우저에서는 F5 대신 화면의 **저장** 버튼을 사용하세요. 저장은 해당 브라우저에만 남으며 사이트 데이터 삭제·비공개 모드에서는 유지되지 않을 수 있습니다. 아이폰 실기기 검증은 별도입니다.

로컬 웹 내보내기: Godot 4.4.1 Export Templates 설치 후 `godot --headless --export-release Web build/web/index.html` (먼저 `build/web` 폴더 생성). 파일을 직접 열지 말고 HTTP 서버로 실행하세요.

## 해 볼 일

- 위쪽 가까운 돌벽에 다가가 3번 클릭해서 공간을 넓힙니다. 벽 하나당 돌 2개를 얻습니다.
- 횃불·작업대·화분을 골라 가까운 빈칸에 놓습니다. 시작 재료는 돌 12개입니다.
- 가구 앞뒤를 걸으며 가림과 발 위치를 확인합니다.
- **조명** 버튼으로 밝기와 그림자를 비교합니다.
- 저장한 뒤 다른 곳으로 이동하거나 가구를 바꾸고, 불러오기로 복원을 확인합니다.

## 조작

| 행동 | PC | 화면 버튼 |
|---|---|---|
| 이동 | WASD / 방향키 | 왼쪽 방향 패드 |
| 채굴·선택 가구 배치 | 대상 칸 클릭 / E·Space로 앞 칸 사용 | 사용 |
| 선택 | 1 곡괭이 / 2 횃불 / 3 작업대 / 4 화분 | 하단 도구 버튼 |
| 회수·재료 환급 | 대상 칸에 마우스를 대고 Q / 우클릭 | 앞 칸 회수 |
| 배치 방향 | R | 회전 |
| 저장 / 불러오기 | F5 / F9 (게임 창에 포커스) | 저장 / 불러오기 |
| 조명 비교 | L | 조명 |

화면 버튼은 모바일 입력 검증용으로도 제공됩니다. **아이폰 실기기·멀티터치는 아직 확인하지 않았습니다.** 저장은 기기의 `user://mosslight-v1.json`에 수동으로 기록됩니다. 기존 게임 세이브와 호환되지 않습니다.

## 범위

구현: 고정 카메라, 평면 격자 충돌·모서리 이동, 3회 채굴, 재료 비용과 회수, 3종 가구, Y 정렬, Godot 실시간 2D 조명·벽 그림자, 저장/불러오기, 화면 폭에 따른 HUD 배치.

아직 없음: 전투·몬스터·멀티플레이, 본편 아이템/레시피 전체 이전, 600×600 지도와 청크, 자연 지형 자동 경계, 광석 12조합, 전체 방향별 가구 그림, 자동 저장. 회전은 데이터·방향 표시와 작업대의 간단한 표시만 바꾸며 완성된 4방향 아트가 아닙니다.

**3D 메시 기반 구현이 아닙니다.** 2D 텍스처·높은 벽 앞면·Y 정렬·조명으로 2.5D 느낌을 검증합니다. 정식 엔진 이전 결정과 본편 개발 순서는 변경하지 않습니다.

## 새 콘텐츠 만들기

- 가구 이름·가격·충돌·빛: `data/furniture.json`
- 게임 규칙과 저장 형식: `scripts/world_state.gd`
- 가구·나무 표시: `scripts/pixel_prop.gd`
- 바닥 표시: `scripts/ground.gd`
- 입력·HUD·조명 연결: `scripts/game.gd`
- `main.tscn`의 루트에서 이동 속도·카메라 배율·기본 조명색을 Inspector로 조절할 수 있습니다.

이번에는 가구 정의와 규칙 분리를 먼저 검증합니다. 임의 JSON 가구가 자동으로 도구칸에 추가되지는 않습니다. 새 가구를 플레이어가 선택하려면 `make_hud()`의 목록에 추가하고, 별도 외형이 필요하면 `pixel_prop.gd`에 그림을 연결해야 합니다. 화면은 실행 시 생성되므로 아직 장면 편집기에서 모든 가구·UI를 드래그해 편집하는 제작 도구는 아닙니다.

## 검사

```sh
godot --headless --path . --editor --quit
godot --headless --path . --script tests/test_world.gd
godot --headless --path . -- --smoke
```

규칙 검사: 잘못된 저장을 읽어도 현재 세계가 보존되는지, 중복 채굴 보상이 없는지, 가구 충돌·재료 거래가 맞는지 포함합니다. 실행 결과와 남은 검증은 `docs/VALIDATION.md`에 기록합니다.

## 아트 출처

첨부 `lantern-handoff (2).zip`의 `lantern-light-demo.html` 안에 포함된 이끼·물·벽 텍스처와 캐릭터 프레임을 사용했습니다. 텍스처는 **사용자가 직접 제작한 그림을 가공한 자산**입니다. 원본 판매용 JPG 시트와 HTML 데모는 저장소에 올리지 않습니다. 나무·작업대·화분 등은 시제품용 코드 그림입니다. 적용 내역은 `docs/HANDOFF-APPLIED.md`를 참고하세요.

한국어 글꼴: Noto Sans KR의 시제품 사용 글자 부분집합. SIL Open Font License는 `assets/fonts/OFL.txt`에 있습니다. 새 문구에 없는 글자가 보이면 전체 Noto Sans KR로 교체하거나 부분집합을 다시 만들어야 합니다.
